Project Description
EvenSplit is a Java-based group expense management and settlement optimisation system designed to simplify the process of sharing expenses among friends, roommates, or groups.
The application allows users to create groups, add members, record shared expenses, calculate individual balances, and determine the minimum transactions required to settle outstanding debts.
The primary objective is to reduce the complexity of manual expense calculations and make group payments more organised and transparent.
How to Run the Program
Prerequisites:
	•	Java Development Kit (JDK 8 or above).
	•	IntelliJ IDEA or any Java-compatible IDE.
	•	Basic knowledge of Java and object-oriented programming.
Steps:
	1	Clone or download this repository.
	2	Open IntelliJ IDEA.
	3	Select Open and choose the downloaded EvenSplit project folder.
	4	Allow IntelliJ IDEA to configure the Java project.
	5	Navigate to src/com/evensplit/Main.java.
	6	Run the Main class.
Alternatively, compile and execute using the terminal:
javac -d out src/com/evensplit/*.java
java -cp out com.evensplit.Main
Features Implemented
	•	Group Management: Create and manage expense-sharing groups.
	•	Member Management: Add members to groups and maintain their information.
	•	Expense Management: Record and manage shared group expenses.
	•	Expense Splitting: Calculate individual contributions and outstanding balances.
	•	Settlement Calculation: Determine who owes money and who should receive payments.
	•	Settlement Optimisation: Minimise the number of transactions required to settle group expenses.
	•	Balance Tracking: Maintain individual financial balances within a group.
Technologies Used
	•	Java
	•	Object-Oriented Programming (OOP)
	•	Java Collections Framework
	•	IntelliJ IDEA
